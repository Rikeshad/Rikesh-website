DESKTOP SYSTEM

Pizza Shop POS

A desktop point-of-sale system I built for the everyday work of a pizza shop, from taking orders and managing stock to reporting and staff administration.

Electron JavaScript MySQL Desktop UI POS Workflow
PROJECT STORY

WHY IT
MATTERS.

Ordering first

Order entry is kept simple so staff can move quickly while still seeing the customer and product information they need.

Operational visibility

Inventory, preparation, order history and reporting give staff a wider view of day-to-day store activity.

Built to scale

The system can be extended for different staff roles and more than one store location without changing the main workflow.

THE COMPLETE PICTURE

Every screen.
Every detail.

Select any screenshot to inspect its original resolution.

01 / Secure Login

Provides a dedicated sign-in screen so authorised team members can enter the POS before accessing operational functions.

02 / POS Home

Acts as the central starting point for the store, bringing core ordering and operational functions into one interface.

03 / Taking an Order

Lets staff select products, build an active order and move quickly through the ordering process during busy service.

04 / Customising a Pizza

Supports pizza customisation so options and toppings can be adjusted before the item is added to the order.

05 / Finalising an Order

Provides a review step for the order, totals and completion workflow before the transaction is finalised.

06 / Customer-Facing Screen

Separates the customer view from the staff interface so order information can be presented clearly during service.

07 / Preparation Page

Gives staff a focused view of items being prepared and helps move orders through the production stage.

08 / Order History

Allows previous orders to be reviewed so staff and management can look back at completed transactions and order details.

09 / Adding Menu Items

Supports maintaining the menu catalogue by adding products and keeping the items available to staff up to date.

10 / Menu Optimisation

Provides a management view for reviewing and refining the menu currently presented through the POS.

11 / User Management

Supports managing system users and staff access so the POS can be used across different roles.

12 / Inventory Management

Tracks ingredient quantities, stock levels, suppliers and reorder information so the store can understand what is healthy, low or out of stock.

13 / Daily Sales Report

Supports daily cash and till reconciliation by recording denominations and helping staff compare counted cash with expected takings.

14 / Sales Period Reporting

Provides weekly, fortnightly and monthly reporting views that separate sales, payment activity, discounts, refunds and other financial information.

15 / Multi-Store Support

Shows how the application can support deployment across multiple store locations rather than being limited to a single shop.
