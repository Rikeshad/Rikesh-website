01 / PROJECT

Pizza Shop POS

A desktop point-of-sale application designed to help a pizza shop manage orders, customers, payments, inventory, menu items and everyday business operations from one system.

01 / ABOUT

About the Project

The Pizza Shop POS project was created to provide a practical point-of-sale solution for a pizza business. The system brings ordering, customer information, payments, inventory and reporting together in one desktop application.

02 / FEATURES

Key Features

Order Management

Create and manage customer orders while keeping order information organised throughout the ordering process.

Menu Management

Manage pizzas, products, categories, options and pricing from within the POS system.

Customer Management

Store and retrieve customer information such as phone numbers and delivery details.

Payments

Record and manage payment information connected to customer orders.

Inventory

Track stock and inventory information to support everyday pizza shop operations.

Reports

Provide useful business information including orders, payments and daily sales reporting.

03 / TECHNOLOGY

Technology Used

The application uses modern web technologies inside a desktop environment, with MySQL providing the database layer.

Electron.js HTML CSS JavaScript Node.js MySQL
04 / PURPOSE

Project Goal

The goal of this project is to build a reliable and easy-to-use desktop POS system that supports the main operations of a pizza shop while providing a simple workflow for staff and management.
